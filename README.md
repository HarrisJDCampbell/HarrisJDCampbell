### 🚀 things i've shipped

**🏀 [VisBets](https://visbets.com/)** · player-prop analytics for bettors, live on the App Store with paying subscribers.
- the full picture on a player before you decide: game logs, matchups, situations, injuries, line movement
- NBA · WNBA · NFL · MLB · NHL · soccer · F1 · MMA · CS2
- Expo / React Native app, Node + TypeScript API on Railway, Postgres on Supabase, Redis cache
- 40+ scheduled pipelines for ingest, live games, odds snapshots and injury news, monitored with Sentry
- VisPlus / VisMax subscriptions through Apple IAP + RevenueCat
- analytics only: no wagers, no user funds

**🧭 [Atlas](https://github.com/HarrisJDCampbell/atlas)** · a local-first command center for students who build things.
- native macOS app in Tauri (Rust + React); every agent runs on your own machine through Ollama
- one rule throughout: if code can establish a fact, code establishes it, and the model gets that fact as input
- Java interview practice graded by actually running your code: tests, a stress test against a reference, and Big-O timed at doubling n
